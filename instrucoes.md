# Memória do Projeto: BLK Dashboarding

## Objetivo
Criar uma API/Interface em Python para processamento de modelos de blocos, geração de relatórios e dashboards interativos.

## Funcionalidades Principais
- Upload e listagem de CSVs (modelo de blocos e opcionalmente banco de dados).
- Mapeamento dinâmico de variáveis (Tonelagem/Volume, Teores, Categorias).
- Relatórios detalhados com estatísticas, validação de extrapolação e anomalias.
- Dashboards interativos (Treemaps, Histogramas, Curvas Teor-Tonelagem).
- Suporte a dicionário de cores customizado.

## Tecnologias Sugeridas
- **Streamlit**: Para a interface e dashboards.
- **Pandas**: Para processamento de dados.
- **Plotly Express**: Para visualizações.

## Convenções de Código
- Nomes de variáveis em português (conforme o README).
- Identificação de variáveis case-insensitive.
- Formatação de números: separador de milhar como espaço, sem casas decimais para totais.
